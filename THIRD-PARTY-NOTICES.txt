===============================================================================
NOT DISTRIBUTED BY THIS PROJECT
===============================================================================

Setup and the TV's app library download the following on the box itself, from
their publishers' own sources, at install time. None of it is in the exe, in
setup.zip or in this repository; each comes under its publisher's own license
and terms, which the box's owner accepts by installing it.

- winget (App Installer) and its dependencies (VCLibs, Windows App Runtime),
  from the microsoft/winget-cli releases on GitHub.
- HEVC Video Extensions from Device Manufacturer (Microsoft Store id
  9N4WGH0Z6VHQ), from Microsoft's Store delivery service.
- The apps in setup\catalog.json, through winget or their own GitHub releases:
  VacuumTube (YouTube, github.com/shy1132/VacuumTube), Stremio, Jellyfin Media
  Player, Moonlight, and from the library Kodi, VLC, Plex HTPC, Spotify, Feishin.
- Edge extensions, installed by Edge itself from its add-on stores through
  policy: uBlock Origin Lite, FrankerFaceZ, Video Speed Controller.
- Device drivers, from Windows Update (the Bluetooth adapter's, and the Drivers
  step's).
- Microsoft Edge and the WebView2 Runtime, which Windows provides and updates.

Website tiles (Twitch, Netflix and the others) only open those sites in Edge.
