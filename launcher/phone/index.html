Send to TV from other apps

A link shared from any app (browser, YouTube, Reddit…) plays on the TV. Set it up once on each phone.

iPhone: a Shortcut

  1. Make a key for the Shortcut:
  2. In the Shortcuts app: + › Add Action › Get Contents of URL.
  3. URL:
  4. Tap the arrow next to it: Method POST.
  5. Headers › Add new header: Key Authorization, Text:
  6. Request Body JSON › Add new field › Text: Key url, Value Shortcut Input.
  7. Shortcut details (ⓘ): Show in Share Sheet on, for URLs and Text. Name it “Send to TV”.

Keep the key private: with it, anything on your home network can send the TV links. Remove it any time in Settings › Phone remote on the TV.

Android: the remote as an app, in Share

  1. Download the TV box’s certificate: Download
  2. Android Settings › Security › More security settings › Encryption & credentials › Install a certificate › CA certificate › Install anyway, and pick “tv-box.crt” (the names differ a little between phones).
  3. Check it before going on: Encryption & credentials › Trusted credentials › User › tap it. Its SHA-256 fingerprint must be the one the TV shows (Settings › Phone remote, card 2). This page says: If it differs, remove it there and stop: something else answered for the TV box.
  4. Open the secure remote and pair it with the code on the TV.
  5. There: ⋮ › Install app (or Add to Home screen › Install).
  6. Then in any app: Share › TV remote.

Android then says the network may be monitored: that is this certificate. It works only for tv.local and addresses on home networks, never for other sites.
